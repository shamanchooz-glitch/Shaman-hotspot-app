Connexion par ticket

Étape 1 · Rejoindre le réseau

Ouvrez les réglages Wi-Fi de votre téléphone et connectez-vous à :

WI-FI 6 SHAMAN HOTSPOT

Réseau ouvert — aucun mot de passe requis pour rejoindre le Wi-Fi. Le code de votre ticket sert uniquement à activer votre accès internet, une fois connecté.

Étape 2 · Votre ticket

Scannez le QR code imprimé sur le ticket, ou saisissez le code à 5 chiffres.
